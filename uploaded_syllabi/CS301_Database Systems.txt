COURSE DESCRIPTION:
This course covers the design, implementation, and use of database systems.
Topics include the relational model, SQL, normalization, transactions, indexing,
and an introduction to NoSQL databases. Students will design and build a
database application as a final project.

COURSE TOPICS (Week by Week):
Week 1:  Introduction - Database Concepts, DBMS Architecture
Week 2:  Relational Model - Tables, Keys, Constraints
Week 3:  ER Modeling - Entities, Relationships, Cardinality
Week 4:  ER to Relational Mapping
Week 5:  SQL Basics - SELECT, WHERE, ORDER BY
Week 6:  SQL Joins - Inner, Outer, Self
Week 7:  Aggregation and Subqueries
Week 8:  Normalization - 1NF, 2NF, 3NF, BCNF
Week 9:  Indexing - B-Trees, Hash Indexes
Week 10: Transactions - ACID, Isolation Levels
Week 11: Concurrency Control - Locking, Deadlocks
Week 12: Query Optimization
Week 13: NoSQL - MongoDB, Key-Value, Document Stores
Week 14: Review and Project Demos
