COURSE DESCRIPTION:
This course introduces students to the fundamental concepts, algorithms, and
applications of artificial intelligence. Topics include search algorithms,
knowledge representation, machine learning basics, neural networks, and ethics
in AI. Students will implement several AI algorithms in Python.

PREREQUISITES:
- CS201: Data Structures and Algorithms
- MATH210: Linear Algebra
- Basic proficiency in Python programming

LEARNING OUTCOMES:
Upon successful completion of this course, students will be able to:
1. Explain core AI concepts and search strategies
2. Implement basic machine learning algorithms from scratch
3. Design and evaluate simple neural networks
4. Analyze ethical implications of AI systems
5. Apply AI techniques to real-world problems

COURSE TOPICS (Week by Week):
Week 1:  Introduction to AI - History, Definitions, Applications
Week 2:  Intelligent Agents - Types, Environments, PEAS framework
Week 3:  Uninformed Search - BFS, DFS, Uniform Cost Search
Week 4:  Informed Search - A*, Heuristics, Greedy Best-First
Week 5:  Adversarial Search - Minimax, Alpha-Beta Pruning
Week 6:  Constraint Satisfaction - Backtracking, Arc Consistency
Week 7:  Knowledge Representation - Propositional Logic, First-Order Logic
Week 8:  Introduction to Machine Learning - Supervised vs Unsupervised
Week 9:  Linear Regression and Classification
Week 10: Decision Trees and Random Forests
Week 11: Neural Networks - Perceptrons, Backpropagation
Week 12: Deep Learning Basics - CNNs, RNNs
Week 13: Natural Language Processing - Tokenization, Embeddings
Week 14: AI Ethics - Bias, Fairness, Privacy, Accountability
Week 15: Review and Project Presentations
