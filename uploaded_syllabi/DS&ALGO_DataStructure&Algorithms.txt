COURSE DESCRIPTION:
This course provides a comprehensive study of fundamental data structures and
algorithms essential for efficient problem-solving in computer science.
Students will learn to analyze algorithmic complexity, choose appropriate data
structures, and implement efficient solutions in Python and C++. The course
emphasizes both theoretical understanding and practical implementation.

PREREQUISITES:
- CS101: Introduction to Programming
- MATH120: Discrete Mathematics
- Proficiency in at least one programming language (Python preferred)

LEARNING OUTCOMES:
Upon completion, students will be able to:
1. Analyze time and space complexity using Big-O notation
2. Implement core data structures (arrays, lists, stacks, queues, trees, graphs, hash tables)
3. Apply sorting and searching algorithms appropriately
4. Design efficient algorithms using recursion, divide-and-conquer, and dynamic programming
5. Compare algorithmic trade-offs in real-world scenarios

COURSE TOPICS (Week by Week):
Week 1:  Introduction - Algorithms, Complexity, Big-O Notation
Week 2:  Arrays and Dynamic Arrays - Implementation and Analysis
Week 3:  Linked Lists - Singly, Doubly, Circular
Week 4:  Stacks and Queues - Array vs Linked Implementations
Week 5:  Recursion - Base Cases, Call Stack, Tail Recursion
Week 6:  Sorting Algorithms - Bubble, Insertion, Selection, Merge, Quick
Week 7:  Searching - Linear, Binary, Interpolation
Week 8:  Hashing - Hash Functions, Collision Resolution, Hash Tables
Week 9:  Trees - Binary Trees, BST, Tree Traversals
Week 10: Balanced Trees - AVL, Red-Black, B-Trees
Week 11: Heaps and Priority Queues
Week 12: Graphs - Representations, BFS, DFS
Week 13: Graph Algorithms - Dijkstra, Bellman-Ford, MST (Kruskal, Prim)
Week 14: Dynamic Programming - Memoization, Tabulation
Week 15: Greedy Algorithms and NP-Completeness Overview
